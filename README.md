## 🎯 Objetivo Pedagógico

O **UNPCODE** foi criado para proporcionar um ambiente idêntico, estável e livre de conflitos de instalação para todos os alunos das disciplinas de programação, permitindo programar em C, C++, Java, Python e JavaScript sem precisar instalar nada no computador pessoal.

---

## 🛠️ Conteúdo do Repositório

- 📁 `c/` — Códigos introdutórios de lógica, vetores e funções em C
- 📁 `java/` — Classes, objetos e exercícios iniciais em Java
- 📁 `html/` — Estruturação de páginas web e formulários
- ⚙️ `.devcontainer/` & `.vscode/` — Automação da máquina virtual e extensões oficiais
